    <h2 id="role">Focus</h2>
    <p>
      <strong>Python</strong> is the thinner part of the portfolio today compared with
      R, SQL, and Tableau — used for <strong>data prep, light EDA, and scripting</strong>
      where notebooks or small pipelines fit. This page stays honest about scope and
      will grow as more public examples land on GitHub.
    </p>

    <h2 id="problem">Problem</h2>
    <p>
      Some tasks are awkward in a BI tool alone: repeatable cleaning scripts,
      quick API-to-table pulls, or notebook-style exploration before a dashboard.
      Python covers that middle ground between spreadsheet and full app.
    </p>

    <h2 id="what-i-did">What I did</h2>
    <ul>
      <li>Small <strong>pandas</strong>-style cleaning / transform scripts on tabular data.</li>
      <li>Exploratory checks (shape, missingness, simple group metrics) before viz.</li>
      <li>Notebook or script structure that can be re-run with a new file drop.</li>
      <li>Complement to stronger R and SQL work — not a claim of heavy ML production systems.</li>
    </ul>
